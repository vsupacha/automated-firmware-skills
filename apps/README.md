# apps

Projects generated by the skills, laid out exactly as each dev tool expects. Two kinds of content
live here:

- **Published sample apps** (committed): sources, BSP (incl. generated sources), `tests/` and the
  app record (`pse84-app.env` for modus-psoc-e84, `cubemx-app.env` for cubemx-stm32c5 - with its
  `<app>.ioc2`, `pico-app.env` for pio-rpi-pico-2w, with
  `APP_PUBLISHED=1`). They show what a skill
  produces and can be rebuilt directly.
- **Your working apps** and the per-PC workspace (git-ignored): `mtb_shared/`, `.cache/`,
  `.bench/` (probe serials, COM ports), `*/build/`, `*/.pio/`, `*/mx/`, `*/.mx/`, `*/logs/`.

## Rebuild a sample (modus-psoc-e84)

```bash
bash skills/modus-psoc-e84/scripts/build.sh apps/hello-edgi --getlibs
```

## Publish one of your apps

1. Build PASS (and test PASS if a board is available), with the verification line added to the
   board profile README.
2. Add `APP_PUBLISHED=1` to its `pse84-app.env` - `clean.sh` then removes only its build outputs.
3. Delete `.mtbqueryapi` files and check `git status` shows no `build/`, `libs/`, `logs/`.
4. Add a row to the table above.
